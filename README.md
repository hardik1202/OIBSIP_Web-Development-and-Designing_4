# Login Authentication
A simple web-based **Login Authentication System** built with **HTML**, **CSS**, and **JavaScript**.  
---
## Features
- **User Registration**: Create a new account with a username and password
- **User Login**: Secure sign-in mechanism
- **Auth Guard**: Protects the dashboard from unauthorized access
- **LocalStorage Database**: User accounts are saved locally in your browser
- **Session Protection**: Uses `sessionStorage` for active login sessions
- **Attractive UI**: Premium styling with gradients, cards, and FontAwesome icons
- **Inspirational Dashboard**: Features career inspiration and quotes from A. P. J. Abdul Kalam

## How to Use
1. Open `register.html` in your web browser.
2. Enter a username and password to create an account.
3. Click the link to go to `login.html`.
4. Enter your credentials and press **Sign In**.
5. Once logged in, you will be redirected to the **Dashboard** (`index.html`).
6. Read the inspirational quotes and click **Logout** to end your session.
